    Identitas dan batas cakupan

    Data diambil langsung dari PDDIKTI. Hasil hanya ditampung sementara pada memori halaman; memuat ulang halaman atau mengambil data terbaru akan memulai sesi baru.

    API homebase mengembalikan daftar per prodi. Karena belum ada endpoint gabungan seluruh dosen Aceh dengan pagination, halaman berikutnya memuat prodi berikutnya sesuai kebutuhan. Total akhir tersedia setelah seluruh cakupan selesai.

    Gunakan Muat seluruh cakupan untuk menelusuri semua prodi pada PT/status yang dipilih. Ketik untuk menyaring hasil yang dimuat, atau pilih Cari seluruh Aceh untuk mencari nama/NIDN/NUPTK melalui API pencarian PDDIKTI dan mencocokkan kampusnya dengan daftar PT Aceh. Hasil pencarian API mengikuti data terkini dari sumber, terpisah dari direktori semester. Urutan alfabet direktori tersedia setelah cakupan selesai dimuat. Pemuatan dapat dijeda.

    Dosen digabung berdasarkan NIDN, NUPTK, atau ID SDM. Dosen bernama sama tidak digabung hanya berdasarkan nama.

    Unduhan berisi hasil yang sudah dimuat, dan CSV mencatat satu baris per afiliasi. Cakupan mengikuti pelaporan homebase PDDIKTI untuk semester terpilih.
